## Findings
1. [nit] With any prompt open, the transcript ignores the mouse: `src/app/mouse.rs`, `takes_mouse`, `Id::Transcript | Id::Subagent(_) => !prompt`. The test `an_open_prompt_keeps_the_transcript_from_the_mouse` pins this. §1.4 exempts only overlays from "acts on the element under the pointer whether or not it has focus".
   - **Ruling: not blocking.** The prompt replaces the help line and does not cover the transcript. But the browser search is not incremental: results arrive only after `Enter` closes the prompt (`transcript_prompt_submit`), so the transcript is not a results pane while the prompt is open. This differs from 034's Sessions-during-search case.
   - Taking clicks would also move focus off the prompt through `focus_transcript` and break input mode.
   - Change (optional): let the wheel through while the search prompt is open (`!prompt || (self.browser.search.prompt_open && wheel)`), and keep clicks and the path and `y/n` prompts modal. Otherwise, record the decision in the module docs as a deliberate exception to §1.4.
2. [nit] `src/app/browser_tests/mouse.rs`, `the_wheel_moves_the_selection_to_the_topmost_fully_visible_section`: it only asserts that the selection is no longer the first section and that a `▒` row is on screen. It does not check "topmost fully visible". The component test covers the rule, so the AC is met. Change: assert that the selected section's rows (from `presentation.selected`) are the first fully visible ones in the transcript area.
3. [nit] `src/app/mouse_tests.rs`, `nothing_under_the_help_overlay_or_the_theme_selector_gets_the_mouse`: this test lost its wheel assertions. Nothing now checks that a wheel step inside an overlay over the startup panes leaves the pane under it alone. Change: add a wheel step at the same covered points and assert that the project and session selection are unchanged.
4. [nit] `WHEEL_ROWS = 3` is defined twice, in `src/components/help_overlay/mod.rs` and in `src/components/transcript/keys.rs`. Change: share one constant, for example in `components/mod.rs`, or refer to the transcript's from the help overlay.
