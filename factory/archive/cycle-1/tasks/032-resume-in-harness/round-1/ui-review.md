## Findings
1. [nit] Missing-cwd toast, any path (even the short fixture path `/home/user/projects/brio`), at terminal widths 60–63 (e.g. 60x24).
   - **Problem:** `missing_dir_toast` sizes the path cut for `MAX_TOAST_WIDTH - TOAST_CHROME` (56 columns). But `toast_rect` makes the box only `min(MAX_TOAST_WIDTH, width - 4)` wide. At 60 columns the 56-character text is therefore cut at its end by the `Toast`, and it reads `Cannot resume: /home/user/projects/brio no longer e…`. The suffix that the start-cut is meant to keep is lost. Task 026's success toasts had the same nit.
   - **Change:** cut the path for the box width actually used: `MAX_TOAST_WIDTH.min(screen_width.saturating_sub(4)) - TOAST_CHROME`, minus the prefix and suffix widths. Either pass the current screen width into `missing_dir_toast`, or let the `Toast` apply the start-cut when it renders. At 60 columns the toast would then read `Cannot resume: …/user/projects/brio no longer exists`.
   - See `ui/missing-cwd-toast-60x24.txt`.
