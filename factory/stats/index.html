How many rounds each task needed

Round 1 is the build and full review. If any review fails, the factory runs one automatic fix round. After that, each REWORK verdict adds a round, up to two per task, and a human can add more with /factory rework.

    How these numbers were counted
    • The data comes from factory/stats/extract.py, which writes factory/stats/data/. Run it again after archiving a cycle, then reload this page.
    • Rounds, round kinds, review states and verdicts come from each cycle's board.json. The extractor checks that every review's first line and every verdict.md agree with the board.
    • Findings are the [must-fix] and [nit] items under each review's ## Findings heading. Re-checks of earlier findings, under headings such as "Previous findings", are not counted again. Each FAIL review has at least one must-fix and each PASS review none.
    • "Nits found late" are nits marked (found late): issues in code the round did not change.
    • Evidence files are the files in a reviewer's evidence folder for that round.
    • Agent time and tokens come from the Claude Code transcripts of the factory's sessions, read the way chronoscope reads them. A main session's agent time is its "Agent" figure in chronoscope's session selector, which runs from each of your prompts to the end of the turn it started, so it includes the time the session waited for its background agents. An agent's turn runs from the prompt it was given (or the message that resumed it) to its hand-back, and the extractor checks every main session against chronoscope's own stats cache.
    • Turns are matched to tasks and rounds by their prompt, "Task-id: … Round-id: …". Every build, review and verdict in the archive has its agent's transcript. The matched turns are kept in each cycle's usage.json, so the figures stay once Claude Code deletes old transcripts.
    • Runs outside the archived cycles, such as trial runs and the run before cycle 1, are left out; extract.py lists them.
