# Theme Selector

- Up / Down or j / k changes highlighted line and previews the highlighted theme. 
- ENTER selects and closes overlay
- ESC cancels and closes overlay without changing theme.

```
  ╭─ Themes ──────────────────────────────╮ 
  │                                       │
  │    Default                            │
  │  > Terminal                           │
  │    Catpucchin                         │
  │    Gruvbox                            │
  │    Nord                               │
  │    Tokio Night                        │
  │    Solarized                          │
  │                                       │ 
  │ ENTER to select | ESC to cancel       │
  ╰───────────────────────────────────────╯   
```
