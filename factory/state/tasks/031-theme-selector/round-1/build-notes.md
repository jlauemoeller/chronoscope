## Changes
- `src/components/theme_selector/` (new): the `ThemeSelector` component and the `ThemeRows` widget (`rows.rs`). Built from plain data (`ThemeItem`s from `theme_items(&registry)`, the active id, theme, keymap). Keys come only from the keymap's `overlay` context: up/down move the cursor over selectable themes (no wrap, invalid rows skipped) and say `Msg::PreviewTheme(id)` only when the cursor moved; `select` says `SelectTheme`, `close` says `CancelTheme`. Scrolling reuses `ListCursor` (offset kept by the App-announced `VISIBLE_ROWS_ATTR`; `view` has no side effects). The help row is the existing `HelpLine` child with hints from the keymap labels. Size: `max(41, longest label + 10)` x `rows + 5`.
- `src/app/theme_selector.rs` (new): `OpenThemeSelector` / `PreviewTheme` / `SelectTheme` / `CancelTheme` handlers. Opening remembers the original id and `Theme` clone; Esc re-applies that clone (not a re-resolve). Preview resolves with `resolve_by_id(registry, id, env, config.transparent_background)` and pushes `THEME_ATTR` to every themed `Id` incl. `Subagent(1..=depth)` (hidden parents too) and sets `self.theme` so later mounts get it. Late messages after the overlay closed are ignored (e.g. `Esc` then `j` in one tick). `open_session` drops the selector (restoring the theme) next to `drop_help`.
- `src/config/edit.rs` (new): `save_theme(path, id)`. Existing `theme` value: replaced by its byte span (parsed with `toml_edit::Document`), so comments, spacing, line endings and everything else are byte-identical. No `theme` key: `DocumentMut` insert at the root, then the original line endings / missing final newline are restored. Missing file: parent dir created, exactly `theme = "<id>"\n`. Invalid TOML: untouched, `SaveThemeError::InvalidToml` -> toast `Could not save theme: config.toml is invalid`. Other errors -> `Could not save theme: <error>`.
- `src/app/startup.rs`: `AppInit` gains `theme_id` (configured id if usable, else `default`), `env: TerminalEnv` (previews adapt like startup) and `config_path` (`paths.config_file`, so `--config` works later). Two test constructors updated (truecolor env).
- `src/app/layout.rs`: `LayoutInput::theme_selector`; centred/capped like the help overlay, after the screen and before the toast, hidden on a too-small screen. `src/app/selector.rs`: `push_viewports` announces the visible rows.
- `src/components/global_events.rs`: subscribes to the `theme` key -> `Msg::OpenThemeSelector`; the key clause also excludes `ThemeSelector` (so `q`, `?`, `t`, `Ctrl-o` do nothing while open; `Ctrl-c` still quits).
- `src/app/mod.rs`: `Id::ThemeSelector`, the four `Msg`s, new `App` fields; `App::theme_id()` accessor.
