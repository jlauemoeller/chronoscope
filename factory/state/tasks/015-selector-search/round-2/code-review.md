[nit] `src/components/session_list.rs`, `label`: the project name is cut to `(room / 3).max(MIN_PROJECT_WIDTH)` even when the whole `<project> › <title>` fits in `room`. `room` is what is left for the label after the timestamp, gap, dot slot and stats; the new test allows 19 of 40 cells. A fixture project such as `CameraSettings` or `FactoryFight` is then cut to 8 cells whenever it appears in results, even next to a short title that would leave room for the full name. The required `brio` snapshots only have names of 8 cells or fewer, so they are not affected. The builder did what the round-1 UI review asked for, so this stays a nit. 2. [nit] `src/components/prompt.rs`, `is_typed`: any `Ctrl`+`Alt` chord now types its character on every platform. On Linux and macOS a terminal sends `Ctrl-Alt-q` as ESC + `^Q`, which crossterm reports as `Char('q')` with `CONTROL | ALT`, so the prompt inserts `q`. This is the trade-off round 1 asked for and is harmless. Change (optional): add a sentence to the doc comment saying that `Ctrl`+`Alt` chords type on every platform, because a terminal cannot tell them apart from AltGr.
