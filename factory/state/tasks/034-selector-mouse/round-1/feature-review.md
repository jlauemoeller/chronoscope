## Summary
The selector now has mouse support, built as the task asks. `GlobalEvents` sends left presses and wheel steps to the `App` as `Msg::Mouse`, and only when `mouse = true`. The `App` hit-tests against a cached `ScreenLayout`, which comes from the same pure `layout()` that `view` uses. That layout is recomputed from `update`, `resized`, `push_viewports` and `show_toast_for`, never from `view`. The component that is hit turns a `RoutedMouse` with relative coordinates into a `Msg`. I traced every acceptance criterion through the code to a test that would fail if the behaviour were wrong. I re-ran the gate myself: fmt, clippy `-D warnings` and `cargo test` are all green.
