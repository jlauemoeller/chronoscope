## Findings
1. [nit] Notice whose text starts with a newline, or has a control character alone on a line, selected, block width 40 — `NoticeSection` and `section_text` trim only the end of the text, so `\n\nfirst` draws two blank rows with the `▒` marker and copies with the leading newlines. `first\n\u{7}` draws a blank marked row, and a notice of only `\u{7}` is a selectable section with nothing to show, because `item_content` checks `trim()` before control characters become spaces. OpenCode rows cannot reach the leading-newline case because `ending_notice` trims each part, but the next task's Claude notices take the message's text, and the control-character cases can come from either harness because `trim` does not remove them. Change: normalise once, by replacing control characters with spaces and then trimming both ends, and use that in `NoticeSection`, `section_text`, and the blank check in `item_content`. See `ui/notice-leading-newline-40.txt`.
2. [nit] Export of a notice with a backslash, backticks, HTML-like text or a deep indent (`e`, `E`) — `emphasized_lines` escapes only `_` and `*`. A line ending in a backslash exports as `_path C:\temp\_`, whose closing delimiter is escaped, so the underscores show literally. `a\_b` exports as `_a\\_b_`, which parses as `_a\<em>b</em>`. An underscore in backticks gains a visible backslash, because code spans do not process escapes. `got <think> tag` passes through as raw HTML, which a markdown viewer hides, and a proxy's HTML error body in a `provider.transport` message would do the same. A line indented four or more spaces after a blank line becomes a code block with literal underscores. No text is lost from the file. Change: in `emphasized_lines`, backslash-escape every ASCII punctuation character that CommonMark treats as markup (`\`, `` ` ``, `*`, `_`, `[`, `]`, `<`, `>`, `&`), since the notice is plain text, and drop a line's indent when it is four or more columns. Add these cases, including a `<…>` one, to `an_exported_notice_keeps_its_indent_outside_the_emphasis_and_escapes_markers`. See `ui/notice-export-edge-cases.txt`.
