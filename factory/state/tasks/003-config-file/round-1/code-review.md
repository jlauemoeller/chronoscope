If you extend `tests/logging.rs`, adjust its `lines.len() == 2` assertion to match.

[nit] `src/paths.rs:94-149`: the AC says the `Paths::from_dirs` tests use "temp directories", but they use literal fake paths (`/tmp/cfg`, `/tmp/cache`, …). `from_dirs` never touches the filesystem, so the AC's intent is met: no environment mutation and no real user directories. Using literal paths is arguably cleaner. This is recorded only so the deviation from the AC's wording is visible. Change (optional): build the base dirs under a `tempfile::tempdir()` and compare against `base.join(...)`.
3. [nit] `src/config/mod.rs:383-410` (`Reader::take`): the type check matches on the text of `expected` (`"a boolean"`, `"a string"`, …), and the `_ => value.is_table()` arm quietly turns a typo into a table check. Change: introduce a small `enum Expected { Boolean, String, Integer, Table }` with a `Display` impl that produces the "a boolean"/… text, and match on it exhaustively.
4. [nit] `src/config/mod.rs:176-321` (`Config::from_table`): this is a ~145-line function. Change: split it into `read_top_level`, `read_harness`, `read_projects` and `read_keys` helpers for readability. Separately, the `default` strings (`format!("{:?}", …)`, `to_string()`) are built eagerly even when the key is absent or valid. Passing them lazily (e.g. a closure, or formatting only in the warning branch) would avoid this. It is off the hot path and cosmetic.
5. [nit] `src/timestamp.rs:129-158` (`short_format`): composite specifiers that include seconds (`%r`, `%X`, `%c`, `%+`) are left unchanged, so `format_short` still shows seconds for them. The planner notes only require handling `%S`, the fractional specifiers and `%T`, so this is not a spec miss. Change (optional): expand `%r` to `%I:%M %p` and `%X` to `%H:%M`, or document the limitation in the doc comment.
6. [nit] `src/timestamp.rs:69-70`: with `utc = true`, a user format that contains `%z`/`%Z` renders a doubled zone such as `+0000Z` or `UTCZ`. Change (optional): document this on `TimestampFormatter::new`, or skip the `Z` suffix when the format already contains a zone specifier.
7. [nit] `src/config/mod.rs:133-138` (`Config::load` docs): warnings are logged through the `log` facade, so they are dropped if `Config::load` runs before `init_logging`. Change: add a sentence to the doc comment saying callers should call `init_logging(&paths.log_file)` before loading the config. The ordering itself belongs to the later startup task.
