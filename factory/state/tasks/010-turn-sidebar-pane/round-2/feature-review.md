## Findings
1. [nit] `BackgroundFill` (`src/components/background_fill.rs`) has no `insta` snapshot and no test of `on()`, while spec/SPEC.md §9.6 says every component is snapshotted and has its events checked, and every other component in `src/components/` that draws has both. I rate this a nit, not a must-fix, because what §9.6 protects is already covered: the component is rendered alone into a `TestBackend`, and its only output (the background inside its area, `Reset` outside it, nothing when transparent) is asserted cell by cell, which is stricter than a snapshot. Its `on()` is a single `None`. The gap also appears in the styled browser snapshots. The Approver may read §9.6 more strictly. Change: in `background_fill::tests`, add a test that `on()` returns `None` for a key and a mouse event; a `buffer_to_styled` snapshot is optional.
2. [nit] Removing the deselection in `TurnSidebar::sync` (`src/components/turn_sidebar/mod.rs:184-186`) fails no test, because `selected_entry()` also returns `None` for a stale id. The doc comment on `selected` ("It always has an entry") is therefore unchecked, and a turn that regained its entry could silently become selected again. Change: in `a_selected_turn_that_loses_its_entry_is_deselected` (`src/components/turn_sidebar/tests.rs:812`), apply `updated(vec![assistant("a1", 9)])` afterwards and assert `selected_entry()` is still `None`; in `a_selected_turn_that_is_not_in_new_rows_is_deselected` (`tests.rs:802`), push the `wireframe()` rows again and assert the same.
3. [nit] The test list `BROWSER_IDS` (`src/app/browser_tests.rs:444`) still has three ids, so `opening_a_session_mounts_the_browser_unmounts_the_selector_and_starts_a_load` does not check `TurnSidebar` and `SidebarGap` directly. Coverage exists indirectly: removing both from the production list fails 9 tests that open a second session. Change: add `Id::TurnSidebar` and `Id::SidebarGap` to the test list, with the array length.
4. [nit] The doc comment on `hit_test` (`src/app/mouse.rs`) has a short line left over from the insertion ("Components under the topmost overlay are not" / "candidates, ..."). Change: rewrap the paragraph.
